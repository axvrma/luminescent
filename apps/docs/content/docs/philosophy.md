---
title: "Design philosophy"
description: "Beautiful by default. Accessible by design. Engineered for production."
---

## Light serves a purpose

A warm accent marks an action. A fine illuminated edge gives a surface depth. A restrained focus ring makes keyboard position unmistakable. Ambient light should support hierarchy, not compete with the task.

## Familiar interactions matter

A beautiful radio group should still behave like a radio group. Native inputs preserve browser keyboard behavior, form submission, validation, and assistive-technology integration. More complex patterns use established accessible foundations.

## Motion is optional

Animations never carry the only copy of important information. Reduced motion removes cycling and decorative animation. There is no mandatory cursor tracking; a Card spotlight is an explicit choice.

## A system should adapt

Semantic variables connect color, space, typography and effects. Theme containers isolate decisions to one tree. You can make the glow quiet, change the palette, or bring a light surface into a dark application.
