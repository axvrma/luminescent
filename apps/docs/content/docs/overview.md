Luminescent is a React component library with luminous surfaces, native form controls, and a shared design-token system. It supports dark, light, and system themes, plus independently themed trees.

## Start here

1. [Install the package](/docs/getting-started) and import its stylesheet.
2. [Explore the catalog](/docs/components) to choose a building block.
3. [Try the playground](/playground) to tune appearance and copy working code.

## What is included

Native inputs and selection controls, surfaces, feedback, motion components, and Radix-based Dialog, Tooltip, Popover, DropdownMenu, Tabs and Toast. Components expose TypeScript prop types from the package root.

## What remains your responsibility

Compose meaningful labels, contrast-test custom themes, integrate validation and result announcements, and choose appropriate headings. Components cannot determine those application-level decisions.
